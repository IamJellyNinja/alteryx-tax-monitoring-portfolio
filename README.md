## Project Overview

An Alteryx-based data preprocessing and monitoring project designed to identify data quality issues in synthetic GST transaction records.

## Objectives

- Standardise inconsistent transaction data.
- Detect missing values and invalid identifiers.
- Identify inconsistent date formats.
- Validate GST codes and transaction values.
- Integrate business reference data using Alteryx Join.
- Generate data quality exceptions for further review.

## Technical Skills Demonstrated

- Alteryx Designer
- Data Cleansing
- Formula Tool
- Regex Validation
- Date Standardisation
- Data Integration and Joins
- Duplicate Detection
- Exception Handling
- Data Quality Monitoring

## Workflow

Raw Data → Standardisation → Data Quality Validation → Exception Handling → Reference Data Matching → Monitoring Outputs

## Deliverables

1. Cleaned transaction dataset
2. Data quality exception report
3. Business reference enrichment
4. Tax anomaly monitoring output

## Possible Output Tools

Alteryx Designer, Microsoft Excel or Tableau (for downstream visualisation).etc
